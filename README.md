# zenome

Chrome Extension that orchestrates live multi-model AI debates across browser tabs with no API keys — uses live ChatGPT, Gemini, DeepSeek, Grok, Kimi, Qwen, Perplexity sessions

## Features

- chrome-extension
- ai
- multi-model
- manifest-v3
- javascript
- chatgpt
- gemini

## Getting Started

Clone the repo and follow the setup instructions in the code.
